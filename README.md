# 十七个监测器 · Seventeen Monitors

十七个开箱即用的静态监测页面：A股+港股、头部 AI 与 Agent、开源 AI、X、义乌小商品、国内 AI 与 Agent，再加 11 个新监测：AI 工具降价、AI 新品上线、AI 副业拆解、跨境爆款、1688/拼多多价格趋势、节日选品日历、热搜热榜聚合、GitHub Trending 日榜、AI 产品热度日榜、AI 大事件、搜索趋势。

全部是**纯静态 HTML**，不需要后端、不需要数据库、不需要账号密码。
打开 `monitors/` 里的任意一个文件（或用任意静态服务器托管），点右上角**刷新**即可拉取最新公开数据——05 义乌页除外，它的按钮是「载入样本」，只重绘已标注的缓存样本，不拉取实时数据；09、10、11、16 页为人工策展/人工录入，按钮同样只载入样本，不拉取实时数据。

> ⚠️ 免责声明：本项目只展示公开数据，不构成投资建议。股票、基金、AI 模型价格与额度以官方公布为准。

> 设计说明（2026-11-09 改版）：每个监测器有独立配色与渐变背景、彩色 KPI 卡、hero「今日看点」栏；图表类型各不相同（折线、散点、彩色条形等）。Chart.js 已随仓库内置（`monitors/chart.umd.min.js`），离线打开也能画图，CDN 仅作替补。

## 备份硬规则（新增 11 个监测同样适用）

每个数据源都必须有备份：主源 → 替补源 → 缓存，三层标注来源与时间，过期标「已过期」。没有备份的源，页面上明确写「无备份」或「无可用备份源」，绝不假装有备用。

## 冗余规则（本项目最重要的一条）

每个数据源都必须有替补：

1. 主源失败 → 自动切换替补源；
2. 替补也失败 → 显示上次缓存数据，并标明 **「上次数据 / 已过期」**；
3. 没有数据时显示 **「未获取」**，绝不编造数字；
4. 每个模块都标明当前来源（主源 / 替补源 / 缓存）和数据时间。

港股免费行情约延迟 15 分钟，页面上已写明，不冒充实时。
北向资金净买额因港交所不再披露实时买卖金额，只报成交额，不编净买额。

## 本地运行

```bash
# 任选其一
python3 -m http.server 8000
# 或
npx serve .
```

然后打开 http://localhost:8000/monitors/01-a-share-hk.html

直接双击 HTML 文件也能打开，但部分公开接口会因 CORS 拒绝 `file://` 请求，
此时页面会如实显示「未获取 / 缓存」，建议用上面的本地服务器方式运行。

## 数据缺口（诚实说明）

- **01 股票**：腾讯行情是唯一真正解析的主源（逐个代码 `v_sh000001` 等精确匹配）；新浪行情已从代码中移除——实测直连 403 且无 CORS 头，不能当实时替补。腾讯失败即走标注缓存（2026-11-09 14:48 盘中快照），不冒充实时。涨跌家数（725/4483/87）无实时来源，仅作不带日期的缓存样本标注；分时图 7 个点为缓存示例走势，非实时。
- **02 / 06 AI 模型**：代码里根本没有 model-watch，不要再把它当来源；models.dev 接口返回 302，拉不到数据，实际唯一能通的公开目录是 OpenRouter，且它不给分数——分数列只有缓存样本里才有。缓存样本明确标注。
- **03 开源**：主源是 GitHub Core API 逐仓拉取 24 个白名单仓库（topic 搜索已弃用，噪声太大），替补为 GitHub Search API（仅发现）。周增 Star（Δ Star）已实现：本机 localStorage 存每日快照，Δ = 当前 − ≥6 天前快照，不足则标明快照天数；第 1 天只有基线，显示「积累中」。未登录 Core API 每小时限 60 次，一次加载 24 次调用，约 2 次满载后会被 403 截断（已优雅处理，保留已加载部分）。缓存样本为 2026-11-09 核实值并标注。
- **04 X**：trends24 不是可用来源——它只有 HTML 页面且不带 CORS 头，浏览器读不到，代码也不解析，只给链接让人手动打开；本页没有自动化的热搜来源。用户资料走 FxTwitter `/2/profile/{账号}`（主）→ VxTwitter `/{账号}`（替补，无总获赞）；帖子时间线只有 FxTwitter `/2/profile/{账号}/statuses`，VxTwitter 没有时间线接口（404），不做替补。帖子表不展示单帖浏览量。只读，不登录、不发帖、不关注。
- **05 义乌**：义乌购 / 义乌指数官网无公开 JSON 接口，浏览器直接拉取常被拦截；页面用调研核实过的样本作缓存并明确标注「缓存样本」，景气指数 1554.97（+0.55%）明确标注为 **2026年9月样本**，不得当作当前值；按钮是「载入样本」不是刷新。1688 生意参谋完整数据需商家账号，本项目只呈现公开方法，不伪造后台数据。
- **07 降价**：OpenRouter 与 models.dev api.json 均实测 200 可用（2026-11-09）；models.dev 价格是分渠道价，替补只用官方渠道条目，Qwen/GLM/Seed 在替补模式下显示未获取。涨跌对比靠快照差分，首次快照只是基线，需第二次快照才有真涨跌。订阅价/免费额度无稳定免费源，一律显示未获取。
- **08 新品**：OpenRouter/models.dev 新增条目 diff 可用；厂商博客 RSS 部分可用（Anthropic /news/rss.xml 实测 404，标未获取）。今日新品数为 0 是如实值，不是缺失。
- **09 副业**：纯人工策展，无实时源；评级是判断不是审计，样本会过期，需重新策展。声称收入均为原帖宣称，未验证。
- **10 跨境**：无稳定免费实时榜单源；样本 14 天后标已过期，需重新策展。Amazon/Temu/TikTok Shop 实时销量无主源、无备份，本页不提供。
- **11 价格**：样本区间为示例对照，非实测报价；毛利差不含运费、平台费、退货。无免费公开接口，无实时备份。
- **12 日历**：节日日期为固定历法知识，2027 春节 2027-02-06 等已多源核实；七夕标「待复核 ±1 天」、开学季为惯例窗口、2027 放假调休天数未公布故不写。
- **13 热榜**：浏览器直连 0/4（CORS 拦），微博/抖音/B 站缓存为 curl 实测真值（2026-11-09），知乎无可用备份源，显示未获取。
- **14 Trending**：GitHub Search API 带 CORS `*`，https 下应可直连；Trending 原站 HTML 快照需 Actions 回填，尚未建。Search API 不给单日新增 Star，图表标明为总 Star，非日增。
- **15 Product Hunt**：RSS 浏览器 CORS 拦；票数仅收录可核实的 1 条，其余未获取；#1 排名各源不一致，页内如实说明。
- **16 大事件**：人工策展快照，7 天后过期；Actions 快照未建，无自动刷新路径。
- **17 搜索趋势**：趋势图为示意指数（人工设定，非实测），页内三处警告勿当数值引用；百度指数无备份源，页内无百度数据。
