# 六个监测器 · Six Monitors

六个开箱即用的静态监测页面：A股+港股、头部 AI 与 Agent、开源 AI、X、义乌小商品、国内 AI 与 Agent。

全部是**纯静态 HTML**，不需要后端、不需要数据库、不需要账号密码。
打开 `monitors/` 里的任意一个文件（或用任意静态服务器托管），点右上角**刷新**即可拉取最新公开数据。

> ⚠️ 免责声明：本项目只展示公开数据，不构成投资建议。股票、基金、AI 模型价格与额度以官方公布为准。

## 冗余规则（本项目最重要的一条）

每个数据源都必须有替补：

1. 主源失败 → 自动切换替补源；
2. 替补也失败 → 显示上次缓存数据，并标明 **「上次数据 / 已过期」**；
3. 没有数据时显示 **「未获取」**，绝不编造数字；
4. 每个模块都标明当前来源（主源 / 替补源 / 缓存）和数据时间。

港股免费行情约延迟 15 分钟，页面上已写明，不冒充实时。
北向资金净买额因港交所不再披露实时买卖金额，只报成交额，不编净买额。

## 本地运行

```bash
# 任选其一
python3 -m http.server 8000
# 或
npx serve .
```

然后打开 http://localhost:8000/monitors/01-a-share-hk.html

直接双击 HTML 文件也能打开，但部分公开接口会因 CORS 拒绝 `file://` 请求，
此时页面会如实显示「未获取 / 缓存」，建议用上面的本地服务器方式运行。

## 数据缺口（诚实说明）

- **01 股票**：腾讯/新浪行情接口在浏览器里可能被 CORS 拦截，拦截时页面用缓存样本并标注，不冒充实时。
- **02 / 06 AI 模型**：model-watch 快照以 GitHub 仓库实际文件为准；models.dev / OpenRouter 为公开目录接口，无需 key，但有速率限制。
- **03 开源**：GitHub Search API 未登录每小时限 10 次搜索，超限时显示缓存并标注；周增 Star 需要连续多天快照积累，第一天只有基线。
- **04 X**：只读，不登录、不发帖、不关注。公开接口不提供单帖浏览量明细时，页面显示「未获取」，不编数字。热搜来自 trends24 公开榜。
- **05 义乌**：义乌购 / 义乌指数官网无公开 JSON 接口，浏览器直接拉取常被拦截；页面用调研核实过的样本作缓存并明确标注「缓存样本」，并给出官网链接供人工核对。1688 生意参谋完整数据需商家账号，本项目只呈现公开方法，不伪造后台数据。

## 隐私
